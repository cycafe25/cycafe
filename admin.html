Firebase Admin Authentication

Admin access is secured exclusively via Firebase Cloud Authentication. Hardcoded master passwords have been removed. Regular operator/customer accounts are rejected upon login.

Access is checked against the Firebase admins collection using the signed-in account's UID. Email addresses and passwords are never stored in this website or in localStorage.

To authorize another admin, create their Email/Password account in Firebase Authentication, then create admins/USER_UID in Firestore from the Firebase console.
